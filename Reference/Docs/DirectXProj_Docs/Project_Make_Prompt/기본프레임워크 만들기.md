# 기본 생성 
directx 이용한 게임 프레임워크 만들기 버전은 dx11 을 기준으로 하며 기본 unity 엔진처럼 gameobject 를 이용하고 gameobject에 component 를 등록 하면서 각 등록한 컴포넌트등을 start, update, render, destroy 등 기본 클래스가 적용이 되도록 구성 해줘 gameobject 를 기본적생성하면 gameobject안에 transform 클래스 내부 컴포넌트에 있도록 만들어줘 기본적인 파란 화면까지 띄울수 있도록 적용하며 마우스입력, 키보드 입력도 받을수 있도록 만들어줘


# 기획
기본 프로젝트 구조 생성:

소스 코드를 관리할 src 디렉토리를 생성합니다.

src 내부에 기능별로 하위 디렉토리(Core, Engine, Input)를 만들어 코드를 체계적으로 구성하겠습니다.

윈도우 및 DirectX 핵심 기능 구현:

Core 디렉토리에 윈도우 생성 및 메시지 처리를 담당하는 Window 클래스를 작성합니다.

DirectX 11 초기화(디바이스, 스왑 체인 등) 및 렌더링 루프의 기본 로직을 담당할 Graphics 클래스를 작성합니다. 이 클래스에서 배경을 파란색으로 클리어하는 작업을 처리합니다.

입력 관리자 구현:

Input 디렉토리에 키보드 및 마우스 입력을 감지하고 상태를 관리하는 InputManager 클래스를 싱글톤 패턴으로 구현합니다.


GameObject 및 Component 시스템 구축:

Engine 디렉토리에 모든 컴포넌트의 기반이 될 Component 추상 클래스를 정의합니다. 여기에는 Start, Update, Render 등 가상 함수가 포함됩니다.

위치, 회전, 크기 정보를 담는 Transform 컴포넌트를 구현합니다.
GameObject 클래스를 구현합니다.
GameObject는 생성 시 기본적으로 Transform 컴포넌트를 소유합니다.
여러 개의 Component를 추가하거나 가져올 수 있는 기능을 제공합니다.
자신이 가진 모든 컴포넌트의 생명주기 함수(Start, Update, Render)를 호출하는 역할을 합니다.

장면(Scene) 관리 기능 구현:

Engine 디렉토리에 여러 GameObject를 관리하는 Scene 클래스와 이를 관리하는 SceneManager를 구현합니다. 이를 통해 현재 활성화된 씬의 모든 GameObject들이 일괄적으로 업데이트되고 렌더링되도록 합니다.


전체 시스템 통합 및 메인 루프 작성:

지금까지 만든 모든 클래스(윈도우, 그래픽, 입력, 씬)를 총괄하고 게임의 메인 루프를 실행하는 Game 클래스를 Core 디렉토리에 작성합니다.

프로그램의 시작점(main 함수)에서 Game 클래스를 생성하고 실행하는 코드를 작성합니다.


# 답변 
DirectX 11 기반의 게임 프레임워크를 구현합니다.

주요 기능:
- Unity 엔진과 유사한 GameObject-Component 아키텍처
- 모든 GameObject에 기본적으로 Transform 컴포넌트 포함

실시간 셰이더 컴파일 기능 구현:

현재는 미리 컴파일된 셰이더 파일(.cso)을 로드하지만, 앞으로는 셰이더 소스 코드(.hlsl)를 직접 읽어와 게임 실행 중에 컴파일하도록 변경하겠습니다.
또한, 이렇게 런타임에 컴파일된 셰이더를 .cso 파일로 저장하여 캐시로 사용할 수 있는 옵션도 추가하겠습니다.
셰이더 핫 리로딩(Hot Reloading) 시스템 구축:

게임을 끄지 않고도 셰이더 코드의 변경 사항이 즉시 게임 화면에 반영되는 '핫 리로딩' 기능을 구현합니다.
개발 중 .hlsl 파일을 수정하고 저장하면, 시스템이 이를 감지하여 자동으로 해당 셰이더를 다시 컴파일하고 즉시 적용합니다. 이를 통해 셰이더 디버깅 및 개발 속도를 크게 높일 수 있습니다.
핫 리로딩 기능 조건부 컴파일:

핫 리로딩은 개발 시에만 필요한 기능이므로, #define 지시어를 통해 이 기능을 켜고 끌 수 있도록 만들겠습니다.
이렇게 하면 최종 게임 출시 버전에서는 핫 리로딩 관련 코드가 완전히 제외되어 성능 저하를 방지할 수 있습니다.

# 답변 
셰이더 개발 워크플로우를 크게 개선하는 고급 셰이더 시스템을 구현합니다.

1.  **런타임 셰이더 컴파일**: 기존의 미리 컴파일된 `.cso` 파일 로딩 방식 대신, `.hlsl` 소스 코드를 직접 읽어 런타임에 컴파일하도록 `Shader` 클래스를 개선했습니다. `D3DCompileFromFile` API를 사용하며, 컴파일 오류 발생 시 메시지 박스를 통해 즉시 피드백을 제공합니다.

2.  **셰이더 핫 리로딩**: `ShaderManager`를 도입하여, 실행 중에 셰이더 파일의 변경 사항을 감지하고 자동으로 다시 컴파일하여 게임에 즉시 적용하는 핫 리로딩 기능을 구현했습니다.

3.  **조건부 컴파일**: 핫 리로딩 기능은 개발 중에만 필요하므로, `#define HOT_RELOAD_ENABLED` 매크로를 통해 기능을 켜고 끌 수 있도록 하여, 최종 출시 버전에서는 관련 코드가 빌드에 포함되지 않도록 최적화했습니다.
